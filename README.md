# PANURGE STORE

Website katalog source code GTPS (PTHT & modul).

## Fitur
- Desain editorial (light / dark mode)
- Toggle Motion & Air
- Tilt interaktif (desktop)
- Katalog produk + FAQ + cara beli
- CTA Discord

## Struktur
```
panurge-store/
├── index.html
├── style.css
├── script.js
├── .gitignore
└── README.md
```

## Menjalankan lokal
```bash
python3 -m http.server 8080
```
Buka `http://localhost:8080`

## Deploy
- **Replit / Vercel / Netlify / GitHub Pages** — static hosting
- Pastikan repo **Private** jika tidak ingin source website publik

## Catatan
- File produk (SC / PTHT) **tidak** disimpan di repo ini
- Pengiriman hanya melalui Discord setelah pembayaran dikonfirmasi
- Ganti tautan Discord di `index.html` jika diperlukan
